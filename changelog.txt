Excel Navigator - Changelog

v6.1 - CF2Static
- Added CF2Static to the Copy frame.
- CF2Static creates copies of selected workbooks with suffix `_without_conditional_formatting` and converts Conditional Formatting into static formatting using DisplayFormat.
- Conversion covers every Worksheet, including Hidden and VeryHidden sheets.
- Added per-cell visual-format validation and workbook-wide verification that no Conditional Formatting remains.
- Failed conversions are closed without saving and the failed output copy is removed.
- Added guarded application-state handling for ScreenUpdating, EnableEvents, DisplayAlerts, AskToUpdateLinks and Calculation.
- Data Bars and Icon Sets are explicitly rejected because Excel VBA cannot reproduce their rendered graphics as ordinary static cell formatting.
- Updated launcher/interface version to v6.1 and refreshed bilingual Help.

Previous highlights
- Added Compare Files and Snapshot / Compare workflows.
- Added Strict, Value-only and Hybrid snapshot comparison modes.
- Added independent `.xlsx` snapshots with `_snapshot_meta` metadata.
- Added Selection mode keyboard/navigation improvements.
- Added Settings for default copy/open folders and snapshot compare mode.
- Added Copy + Break Links and Copy with suffix workflows.
