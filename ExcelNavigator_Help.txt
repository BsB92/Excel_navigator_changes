Excel Navigator - Instrukcja użytkownika (v6.1) [PL]

1) Ogólny przepływ pracy
- Reload list odświeża listę aktualnie otwartych skoroszytów.
- Search filtruje listę po nazwie i ścieżce.
- Selection mode umożliwia zaznaczenie wielu skoroszytów i wykonanie akcji zbiorczych.

2) Skróty i nawigacja
- S = przełącz Selection mode ON/OFF.
- Ctrl+A = zaznacz wszystkie skoroszyty.
- Ctrl+D = wyczyść zaznaczenie.
- W Selection mode: A dodaje bieżący wiersz do zaznaczenia, D usuwa go z zaznaczenia.
- Strzałki góra/dół = nawigacja po liście; Enter = aktywacja skoroszytu/arkusza.
- Strzałka w prawo/lewo = rozwiń/zwiń panel Sheets.
- Dwuklik w polu pełnej ścieżki kopiuje ścieżkę do schowka.

3) Settings
- Default copy folder ustawia folder startowy dla operacji kopiowania.
- Default open folder ustawia folder startowy dla Open/Open&Refresh oraz pickerów Compare.
- Use active pobiera ścieżkę z aktywnego skoroszytu.
- Snapshot compare mode: Strict, Value-only lub Hybrid.

4) Selection mode
- OFF = wybór pojedynczego skoroszytu.
- ON = wybór wielu skoroszytów i akcje zbiorcze.
- Akcje Refresh selected, Save selected, Refresh + Save, Close selected oraz funkcje kopiowania działają na zaznaczonych pozycjach zgodnie z ich opisem.

5) Akcje otwierania i odświeżania
- Open file = otwarcie jednego lub wielu plików Excel.
- Open&Refresh = otwarcie plików i uruchomienie odświeżania.
- Refresh selected = odświeżenie zaznaczonych otwartych skoroszytów.
- Save selected = zapis zaznaczonych skoroszytów.
- Refresh + Save = odświeżenie, a następnie zapis.
- Cancel w trakcie batch zatrzymuje uruchamianie kolejnych pozycji; aktywnego RefreshAll nie można bezpiecznie przerwać.

6) Akcje kopiowania - frame Copy
- Suffix = suffix używany przez istniejące operacje kopiowania.
- Copy + Break Links:
  * wybiera folder docelowy,
  * tworzy kopię,
  * zrywa zewnętrzne linki Excel/OLE zgodnie z istniejącą logiką.
- Copy with suffix:
  * wybiera folder docelowy,
  * tworzy kopię z podanym suffixem bez zrywania linków.
- Open copied / Open target folder = istniejące opcje po kopiowaniu.

CF2Static:
- działa wyłącznie na plikach zaznaczonych w Selection mode,
- prosi o folder docelowy; okno startuje z domyślnego folderu kopiowania ustawionego w Settings,
- tworzy kopię każdego zaznaczonego pliku i dodaje suffix `_without_conditional_formatting`,
- oryginalne pliki nie są modyfikowane,
- każda kopia jest otwierana programowo bez aktualizacji linków,
- funkcja przetwarza wszystkie arkusze typu Worksheet, również Hidden i VeryHidden,
- dla komórek objętych Conditional Formatting odczytuje aktualnie widoczny format przez DisplayFormat i zapisuje go jako zwykłe formatowanie statyczne,
- zachowywane są m.in. wypełnienie/pattern, font, kolor, NumberFormat i obramowania,
- po zapisaniu statycznego wyglądu wszystkie reguły Conditional Formatting są usuwane,
- po konwersji wykonywana jest walidacja wyglądu każdej przetworzonej komórki oraz kontrola, czy w żadnym Worksheet nie pozostały reguły Conditional Formatting,
- jeśli walidacja nie przejdzie, plik nie jest uznawany za poprawnie przetworzony; nieudana kopia jest zamykana bez zapisu i usuwana,
- Data Bars i Icon Sets nie mają zwykłego, statycznego odpowiednika formatu komórki dostępnego w Excel VBA. Jeżeli zostaną wykryte, konwersja danego pliku jest zatrzymywana i ograniczenie trafia do podsumowania zamiast tworzyć wizualnie niepełną kopię.

7) Close selected
- Zamyka tylko zaznaczone skoroszyty.
- Dodatki i PERSONAL.XLSB są chronione.
- Niezapisane pliki obsługują save-all / don't-save-all / ask-each.

8) Panel Sheets
- >>>> / <<<< pokazuje lub ukrywa listę arkuszy.
- Lista obejmuje arkusze bieżącego skoroszytu i pozwala na nawigację bez ręcznego przełączania kart.

9) Przyciski okna
- Maximize = maksymalizacja okna.
- 1 / 2 / 3 = przeniesienie okna na odpowiedni ekran.
- Close = zamknięcie formularza Excel Navigator.

10) Snapshot / Compare
- Snapshot tworzy niezależny plik `.xlsx` w folderze `.snapshot\NazwaPliku\`.
- Snapshot nie modyfikuje oryginalnego skoroszytu i zawiera `_snapshot_meta`.
- Dostępne akcje: Create Snapshot, Open Snapshot Folder, Compare Latest 2, Compare with Snapshot oraz główny przycisk Compare Files.
- Tryby porównania: Strict, Value-only (zalecany) i Hybrid.
- Raport porównania zawiera Summary i Differences, a zmienione fragmenty formuł są wyróżniane.

Excel Navigator - User Guide (v6.1) [EN]

1) General workflow
- Reload list refreshes the list of currently open workbooks.
- Search filters by workbook name and path.
- Selection mode enables multi-workbook selection and bulk actions.

2) Shortcuts and navigation
- S = toggle Selection mode ON/OFF.
- Ctrl+A = select all workbooks.
- Ctrl+D = clear selection.
- In Selection mode: A adds the current row, D removes it.
- Up/Down = list navigation; Enter = activate workbook/sheet.
- Right/Left = expand/collapse the Sheets panel.
- Double-clicking the full-path field copies the path to the clipboard.

3) Settings
- Default copy folder is the initial folder for copy operations.
- Default open folder is the initial folder for Open/Open&Refresh and Compare pickers.
- Use active derives the folder from the active workbook.
- Snapshot compare mode: Strict, Value-only or Hybrid.

4) Selection mode
- OFF = single workbook selection.
- ON = multiple workbook selection and bulk actions.
- Refresh selected, Save selected, Refresh + Save, Close selected and copy functions operate on selected items as described for each action.

5) Open and refresh actions
- Open file = open one or more Excel files.
- Open&Refresh = open files and run refresh.
- Refresh selected = refresh selected open workbooks.
- Save selected = save selected workbooks.
- Refresh + Save = refresh and then save.
- During batch, Cancel prevents starting further items; active RefreshAll cannot be safely aborted.

6) Copy actions - Copy frame
- Suffix = suffix used by the existing copy actions.
- Copy + Break Links creates a copy in the selected target folder and breaks external Excel/OLE links using the existing logic.
- Copy with suffix creates a copy with the entered suffix without breaking links.
- Open copied / Open target folder are the existing post-copy options.

CF2Static:
- operates only on files selected in Selection mode,
- asks for a target folder; the picker starts from the default copy folder configured in Settings,
- creates a copy of every selected file and appends `_without_conditional_formatting`,
- never modifies the original files,
- opens each copy programmatically with link updates disabled,
- processes every Worksheet in the workbook, including Hidden and VeryHidden worksheets,
- for cells covered by Conditional Formatting, reads the current visible format through DisplayFormat and writes it as ordinary static cell formatting,
- preserves fill/pattern, font, colors, NumberFormat and borders used for the visible appearance,
- removes all Conditional Formatting rules after static formatting is written,
- validates the resulting appearance of every processed cell and checks that no Conditional Formatting remains in any Worksheet,
- if validation fails, the file is not treated as successfully processed; the failed copy is closed without saving and removed,
- Excel VBA has no ordinary static-cell-format equivalent for Data Bars or Icon Sets. If either type is detected, conversion of that file is stopped and the limitation is reported instead of producing a visually incomplete copy.

7) Close selected
- Closes only selected workbooks.
- Add-ins and PERSONAL.XLSB are protected.
- Unsaved workbooks support save-all / don't-save-all / ask-each handling.

8) Sheets panel
- >>>> / <<<< shows or hides the worksheet list.
- The list follows the current workbook and supports keyboard navigation.

9) Window buttons
- Maximize = maximize workbook window.
- 1 / 2 / 3 = move workbook window to the selected screen.
- Close = close Excel Navigator.

10) Snapshot / Compare
- Snapshot creates an independent `.xlsx` under `.snapshot\WorkbookName\` and does not modify the source workbook.
- Snapshots contain `_snapshot_meta`.
- Actions include Create Snapshot, Open Snapshot Folder, Compare Latest 2, Compare with Snapshot and Compare Files.
- Compare modes: Strict, Value-only (recommended), Hybrid.
- Reports contain Summary and Differences and highlight changed formula fragments.
