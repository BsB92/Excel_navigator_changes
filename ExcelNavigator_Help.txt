Excel Navigator - Instrukcja użytkownika (v5.0) [PL]

1) Ogólny przepływ pracy
- Kliknij Reload list, aby odświeżyć listę aktualnie otwartych skoroszytów.
- Użyj Search, aby filtrować po nazwie/ścieżce skoroszytu.
- Wybierz skoroszyt z listy i użyj akcji poniżej.

2) Skróty klawiaturowe i myszy
- Ctrl+A na liście skoroszytów/arkuszy = Zaznacz wszystko (gdy Selection mode jest ON).
- S = włącz Selection mode.
- Strzałka w prawo na liście skoroszytów/arkuszy = rozwiń prawy panel Sheets i przenieś fokus na listę Sheets.
- Strzałka w lewo na liście skoroszytów/arkuszy = zwiń prawy panel Sheets i przenieś fokus z powrotem na listę skoroszytów.
- Strzałka góra/dół na liście skoroszytów = przejdź do poprzedniego/następnego wiersza.
- Enter na liście skoroszytów = aktywuj wybrany skoroszyt.
- Dwuklik na wierszu skoroszytu = aktywuj wybrany skoroszyt.
- Prawy klik na liście skoroszytów = przełącz Selection mode ON/OFF.
- W Selection mode na liście skoroszytów:
  * A = dodaj bieżący wiersz skoroszytu do zaznaczenia.
  * D = usuń bieżący wiersz skoroszytu z zaznaczenia.
- Strzałka góra/dół w panelu Sheets (po prawej) = nawigacja po arkuszach.
- Enter w panelu Sheets = aktywuj wybrany arkusz.
- Pole pełnej ścieżki obsługuje prawy klik (kopiuj/zaznacz).

3) Kontrolki górnego wiersza
- Settings: przełącza ramkę Settings ON/OFF.
  * Stan ON jest podświetlony.
  * Skonfiguruj dwa foldery:
    1) domyślny folder kopiowania
    2) domyślny folder otwierania
  * Save settings waliduje obie ścieżki i zapisuje je.
- ?: otwiera ten plik pomocy.
- Snapshot: otwiera/zamyka ramkę Snapshot / Compare.
  * W ramce dostępne są akcje: Create Snapshot, Compare Snapshot, Snapshot History.

4) Obszar listy skoroszytów
- Kolumny: File / Dir / Sync.
- Wiersz nagłówka nie jest możliwy do zaznaczenia jako cel akcji.
- Aktywny skoroszyt jest wyróżniony wizualnie.

5) Selection mode i akcje zbiorcze
- Selection mode OFF: zachowanie jednokrotnego wyboru.
- Selection mode ON: zachowanie wielokrotnego wyboru i aktywne przyciski akcji zbiorczych.
- Select All / Clear Selection działają tylko w Selection mode ON.

6) Akcje otwierania i odświeżania
- Open file: pozwala wybrać jeden lub wiele plików Excel i je otworzyć.
- Open&Refresh: otwiera wybrane pliki i uruchamia proces odświeżania.
- Refresh selected: odświeża wybrane otwarte skoroszyty.
- Save selected: zapisuje wybrane otwarte skoroszyty.
- Refresh + Save: odświeża, a następnie zapisuje wybrane otwarte skoroszyty.
- W trakcie batch, Cancel zatrzymuje uruchamianie KOLEJNYCH pozycji (nie da się bezpiecznie przerwać aktywnego RefreshAll).

7) Akcje kopiowania
- Suffix: sufiks dodawany do operacji kopiowania (używany dokładnie tak, jak wpisano).
- Copy + Break Links:
  * wybierz folder docelowy
  * utwórz kopię
  * zerwij zewnętrzne linki Excel
- Copy with suffix:
  * wybierz folder docelowy
  * utwórz tylko kopię (bez zrywania linków)
- Open copied checkbox: opcjonalnie automatycznie otwórz skopiowane pliki po operacji.
- Open folder: otwiera ostatnio użyty folder docelowy kopiowania.

8) Akcje zamykania
- Close selected zamyka tylko wybrane skoroszyty.
- Dodatki i PERSONAL.XLSB są chronione przed zamknięciem.
- Obsługa niezapisanych zmian wspiera save-all / don't-save-all / ask-each zależnie od promptu.
- Skoroszyty aktywnie odświeżane są pomijane tam, gdzie to niebezpieczne.

9) Prawy panel Sheets
- Przycisk przełączania panelu (>>>> / <<<<) pokazuje/ukrywa rozszerzony widok arkuszy.
- Lista Sheets podąża za aktywnym skoroszytem.
- Kliknij lub użyj strzałek, aby aktywować wybrany arkusz.

10) Przyciski okna i pozycjonowania
- Max: maksymalizuje okno aktywnego skoroszytu.
- 1 / 2 / 3: przenosi aktywny skoroszyt do zdefiniowanych pozycji ekranu.
- Close: zamyka formularz navigatora.

11) Szczegóły Settings
- Domyślny folder kopiowania jest używany jako folder startowy przy wyborze folderu docelowego kopiowania.
- Domyślny folder otwierania jest używany jako folder startowy dla Open/Open&Refresh.
- Jeśli skonfigurowany folder już nie istnieje, navigator wraca do ścieżki skoroszytu dodatku.

Excel Navigator - User Guide (v5.0) [EN]

1) General workflow
- Click Reload list to refresh the list of currently open workbooks.
- Use Search to filter by workbook name/path.
- Select a workbook from the list and use actions below.

2) Keyboard and mouse shortcuts
- Ctrl+A on workbook/sheets list = Select All (when Selection mode is ON).
- S = turn Selection mode ON.
- Arrow Right on workbook/sheets list = expand right-side Sheets panel and move focus to the Sheets list.
- Arrow Left on workbook/sheets list = collapse right-side Sheets panel and move focus back to workbook list.
- Arrow Up/Down on workbook list = move current row.
- Enter on workbook list = activate selected workbook.
- Double-click workbook row = activate selected workbook.
- Right-click on workbook list = toggle Selection mode ON/OFF.
- In Selection mode on workbook list:
  * A = add current workbook row to selection.
  * D = remove current workbook row from selection.
- Arrow Up/Down on Sheets panel (right side) = navigate sheets.
- Enter on Sheets panel = activate selected sheet.
- Full path box supports right-click copy/select behavior.

3) Top row controls
- Settings: toggles Settings frame ON/OFF.
  * ON state is highlighted.
  * Configure two folders:
    1) default copy folder
    2) default open folder
  * Save settings validates both paths and stores them.
- ?: opens this help file.

4) Workbook list area
- Columns: File / Dir / Sync.
- Header row is not selectable as a workbook action target.
- Active workbook is visually marked.

5) Selection mode and bulk actions
- Selection mode OFF: single-select behavior.
- Selection mode ON: multi-select behavior and bulk action buttons enabled.
- Select All / Clear Selection work only in Selection mode ON.

6) Open and refresh actions
- Open file: lets you pick one or more Excel files and open them.
- Open&Refresh: open selected files and run refresh flow.
- Refresh selected: refreshes selected open workbooks.
- Save selected: saves selected open workbooks.
- Refresh + Save: refresh then save selected open workbooks.
- During batch, Cancel stops starting NEXT items (cannot safely abort active RefreshAll).

7) Copy actions
- Suffix: suffix added for copy operations (used exactly as typed).
- Copy + Break Links:
  * choose target folder
  * create copy
  * break external Excel links
- Copy with suffix:
  * choose target folder
  * create copy only (no link breaking)
- Open copied checkbox: optionally auto-open copied files after operation.
- Open folder: opens last used copy target folder.

8) Close actions
- Close selected closes only selected workbooks.
- Add-ins and PERSONAL.XLSB are protected from closing.
- Unsaved handling supports save-all / don't-save-all / ask-each depending on prompt.
- Workbooks actively refreshing are skipped where unsafe.

9) Right-side Sheets panel
- Toggle panel button (>>>> / <<<<) shows/hides expanded sheets view.
- Sheets list follows active workbook.
- Click or use arrows to activate selected sheet.

10) Window and placement buttons
- Max: maximize active workbook window.
- 1 / 2 / 3: move active workbook to predefined screen positions.
- Close: closes navigator form.

11) Settings details
- Default copy folder is used as initial folder for copy target selection.
- Default open folder is used as initial folder for Open/Open&Refresh file picker.
- If configured folder no longer exists, navigator falls back to add-in workbook path.
