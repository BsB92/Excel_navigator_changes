Excel Navigator - User Guide

1) General workflow
- Click Reload list to refresh the list of currently open workbooks.
- Use Search to filter by workbook name/path.
- Select a workbook from the list and use actions below.

2) Keyboard and mouse shortcuts
- Ctrl+A on workbook/sheets list = Select All (when Selection mode is ON).
- Arrow Right on workbook/sheets list = expand right-side Sheets panel (same as >>>>).
- Arrow Left on workbook/sheets list = collapse right-side Sheets panel (same as <<<<).
- Arrow Up/Down on the workbook list moves selection and activates workbook preview logic.
- Enter on workbook list activates selected workbook.
- Double-click workbook row = activate selected workbook.
- Right-click on workbook list toggles Selection mode ON/OFF.
- Arrow Up/Down on Sheets panel (right side) activates sheet navigation.
- Enter on Sheets panel activates selected sheet.
- Full path box supports right-click copy/select behavior.

3) Top row controls
- Settings: toggles Settings frame ON/OFF.
  * ON state is highlighted.
  * Configure two folders:
    1) default copy folder
    2) default open folder
  * Save settings validates both paths and stores them.
- ?: opens this help file.

4) Workbook list area
- Columns: File / Dir / Sync.
- Header row is not selectable as a workbook action target.
- Active workbook is visually marked.

5) Selection mode and bulk actions
- Selection mode OFF: single-select behavior.
- Selection mode ON: multi-select behavior and bulk action buttons enabled.
- Select All / Clear Selection work only in Selection mode ON.

6) Open and refresh actions
- Open file: lets you pick one or more Excel files and open them.
- Open&Refresh: open selected files and run refresh flow.
- Refresh selected: refreshes selected open workbooks.
- Save selected: saves selected open workbooks.
- Refresh + Save: refresh then save selected open workbooks.
- During batch, Cancel stops starting NEXT items (cannot safely abort active RefreshAll).

7) Copy actions
- Suffix: suffix added for copy operations (auto-prepends _ when needed).
- Copy + Break Links:
  * choose target folder
  * create copy
  * break external Excel links
- Copy with suffix:
  * choose target folder
  * create copy only (no link breaking)
- Open copied checkbox: optionally auto-open copied files after operation.
- Open folder: opens last used copy target folder.

8) Close actions
- Close selected closes only selected workbooks.
- Add-ins and PERSONAL.XLSB are protected from closing.
- Unsaved handling supports save-all / don't-save-all / ask-each depending on prompt.
- Workbooks actively refreshing are skipped where unsafe.

9) Right-side Sheets panel
- Toggle panel button (>>>> / <<<<) shows/hides expanded sheets view.
- Sheets list follows active workbook.
- Click or use arrows to activate selected sheet.

10) Window and placement buttons
- Max: maximize active workbook window.
- 1 / 2 / 3: move active workbook to predefined screen positions.
- Close: closes navigator form.

11) Settings details
- Default copy folder is used as initial folder for copy target selection.
- Default open folder is used as initial folder for Open/Open&Refresh file picker.
- If configured folder no longer exists, navigator falls back to add-in workbook path.
